PaglaMLX is a macOS menu-bar app that runs MLX models locally on Apple
Silicon and puts a reverse proxy in front of them. That proxy, the
gateway, listens on `http://127.0.0.1:2525/v1` and speaks two dialects:

- An **OpenAI-compatible** surface, so any tool built for the OpenAI
  API can point at your local models with no code changes.
- An **Anthropic-compatible** surface, so Claude-native clients can do
  the same.

Every request carries a `model` field. The gateway reads that field
and decides, per request, whether to serve it from a model already
loaded on your machine or forward it to a cloud provider like OpenAI,
Anthropic, Gemini, OpenRouter, Groq, or Together AI. See
[Model routing](/concepts/routing) for the exact order those checks
run in.
